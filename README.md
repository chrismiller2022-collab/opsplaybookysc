# Sports Office Administrator prep

Preparation kit for the Sports Office (sportsoffice365.com) Sports Office Administrator role: a platform learning plan, a portfolio operations playbook for a fictional youth soccer club, and a demo multi-client command-center dashboard.

- Start here: [`CLAUDE.md`](CLAUDE.md), then [`docs/06-next-steps.md`](docs/06-next-steps.md)
- Regenerate the demo data: `python3 scripts/generate_demo_data.py`

All clubs, people and numbers in this repo are fictional.
